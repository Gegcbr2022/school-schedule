# 10-Б — Розклад уроків

Персональний розклад уроків для 10-Б, Ліцей №11 Івано-Франківської міської ради.

Маленький статичний сайт, який ставиться на телефон як застосунок і працює без
інтернету. Показує, який урок іде зараз, скільки до дзвінка, що буде далі, і
вміє показувати розклад окремо «мій» і «повний, з усіма групами».

Ніяких оцінок, домашніх завдань, акаунтів і сервера — тільки розклад.

## Що вміє

- **Що зараз.** Поточний урок із зворотним відліком і смужкою прогресу, перерва,
  «перший урок через N хв», «уроки закінчилися».
- **Свої групи.** Навчальна група (1/2), друга іноземна (німецька/французька),
  підгрупа англійської (А/Б/В). Уроку, якого у вашої групи немає, ви не бачите.
- **Хімія через тиждень.** 8-й урок середи стоїть лише у 2 групи і лише на
  парних тижнях. Тиждень, у якому починається навчальний рік, — перший.
- **Вихідні.** У суботу й неділю показує найближчий навчальний день.
- **Теми.** Світла, темна, або як у системі.
- **Офлайн.** Після першого відкриття працює без мережі.

Час завжди рахується за **Europe/Kyiv**, незалежно від годинника пристрою.

## Запуск локально

```bash
npm install
npm run dev
```

Сайт відкриється на `http://localhost:5173/school-schedule/` — підпапка в адресі
навмисна, бо саме так він живе на GitHub Pages.

## Збірка

```bash
npm run build      # перевірка типів + збірка у dist/
npm run preview    # подивитись зібрану версію (тут працює service worker)
npm run lint
```

Service worker вмикається лише у зібраній версії, тому офлайн перевіряйте через
`npm run preview`, а не `npm run dev`.

## Деплой

Кожен push у `main` запускає `.github/workflows/deploy.yml`: перевірка типів →
лінт → збірка → публікація на GitHub Pages. Нічого робити руками не треба.

У налаштуваннях репозиторію **Settings → Pages → Source** має стояти
**GitHub Actions**.

Базовий шлях заданий у [`vite.config.ts`](vite.config.ts) як `/school-schedule/`
— він має збігатися з назвою репозиторію. Для власного домену зберіть з
`BASE_PATH=/`.

## Де редагувати розклад

Усе в одному файлі: **[`src/data/schedule.ts`](src/data/schedule.ts)**.

- `BELLS` — час уроків. Живе тільки тут, у самих уроках часу немає.
- `SUBJECTS` — скорочення з паперового розкладу → повна назва.
- `WEEK` — уроки по днях.

Урок, який слухає весь клас:

```ts
{ n: 1, subject: 'м' }
```

Урок, поділений на групи:

```ts
{
  n: 4,
  variants: [
    { by: 'classGroup', group: '1', subject: 'ум' },
    { by: 'classGroup', group: '2', subject: 'к' },
  ],
}
```

Якщо в якоїсь групи уроку немає — просто не додавайте для неї варіант.

Урок через тиждень: `onlyWeek: 2` (буває лише на другому, четвертому… тижні).

Поділ, який не змінює предмет, позначається `split`:
`'english'` (підгрупи А/Б/В) і `'gender'` (хлопці/дівчата на фізкультурі).

### Розклад дзвінків

Для 2–11 класів, усі уроки по 40 хвилин:

| Урок | Час | Урок | Час |
|---|---|---|---|
| 1 | 08:00 — 08:40 | 5 | 11:55 — 12:35 |
| 2 | 08:55 — 09:35 | 6 | 12:45 — 13:25 |
| 3 | 09:55 — 10:35 | 7 | 13:40 — 14:20 |
| 4 | 10:55 — 11:35 | 8 | 14:40 — 15:20 |

## Іконки

Іконки згенеровані з [`scripts/generate-icons.mjs`](scripts/generate-icons.mjs)
і вже лежать у `public/icons`. Перегенерувати треба лише якщо міняється малюнок:

```bash
npm i -D sharp && node scripts/generate-icons.mjs
```

## Структура

```
src/
  data/schedule.ts     розклад, дзвінки, предмети — єдине джерело правди
  lib/clock.ts         київський час, дати, парність тижня
  lib/lessons.ts       «мій»/«повний» розклад і стан «що зараз»
  lib/prefs.ts         налаштування в localStorage
  lib/hooks.ts         годинник, тема, кнопка «Встановити»
  components/          шапка з днями, картка стану, стрічка уроків, налаштування
public/
  sw.js                офлайн-кеш
  manifest.webmanifest PWA-маніфест
  icons/               іконки застосунку
```

## Стек

Vite + React + TypeScript, звичайний CSS. Жодних UI-бібліотек і жодного бекенду.
